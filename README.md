# GeoHide Switch 2.2.1

Расширение существующего Android-клиента 2.1.1. DNS-AI по умолчанию использует TLS; Cloudflare/AdGuard/Quad9 — HTTPS, GeoHide — UDP. Повторный выбор профиля включает его стандартный режим. Отдельный режим Авто пробует два шифрованных транспорта только выбранного провайдера.

## Импорт подписки Portal
В режиме полного VPN можно вставить HTTPS-ссылку подписки, например Portal CP-035, нажать «Импортировать», дождаться списка и выбрать один сервер. UTF-8 и Base64 списки ограничены 1 МБ / 1024 профилями. raw трактуется как TCP. Повторы удаляются; XHTTP, отключённая проверка сертификатов и открытые/неподдерживаемые профили пропускаются с пояснениями. Сохраняется только выбранный сервер, без URL подписки и остальных ключей. Совместимость формата не гарантирует работоспособность публичного сервера.

## Новые функции
- Отдельные DNS-профили Wi-Fi, мобильной и другой сети, запоминание успешного транспорта.
- Ограниченный пул TLS и очистка соединений при смене физической сети.
- Проверки ChatGPT, Gemini, YouTube, Telegram и общего интернета по явному запросу, без входа в аккаунт. HTTP 403/429 не объявляются доказанной сетевой блокировкой.
- Сохранение ограниченного диагностического отчёта через системный выбор файла; произвольные DNS-имена, ключи, cookies и конфигурации не записываются.
- Отдельный полный VPN с sing-box 1.14.3 и hev-socks5-tunnel 2.18.0: ss:// с AEAD, vless:// с TLS/REALITY, trojan:// с TLS и JSON одного соответствующего outbound. TCP/WebSocket/gRPC; отключение TLS-проверки и открытые протоколы запрещены.
- VPN-сервер предоставляет пользователь. Автоматического поиска бесплатных серверов и гарантии обхода DPI/белых списков нет. DNS-only и полный VPN работают по очереди в одном VpnService.
- В полном VPN обе IP-семьи маршрутизируются через ядро. DNS идёт по HTTPS к Cloudflare внутри прокси. Само приложение исключено из TUN для защиты от петли; его сервисные проверки явно используют локальный аутентифицированный прокси.
- VPN-конфигурации защищены Android Keystore; резервное копирование приложения отключено. После удаления приложения конфигурацию нужно импортировать снова.

## Сборка и проверка
Java 17, Android SDK 35, Gradle 8.11.1. Нативные библиотеки arm64-v8a, armeabi-v7a, x86_64, ELF 16KB. CI сначала собирает pinned native dependencies (Go 1.25.5 / NDK 27.2.12479018), затем APK, unit tests, lint и Android 15/16 instrumentation.

```
bash scripts/build-native.sh
gradle :app:assembleDebug :probe:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug
bash scripts/device-qa.sh
```

Модуль probe нужен только для проверки TUN из другого UID; в пользовательский APK он не включается. Тестовые сертификаты и localhost-серверы не включаются в обычный APK. SPEC_RU.md содержит актуальное дополнение и исторические ТЗ; DNS_PROVIDERS_RU.md — источники провайдеров.

## Подпись
CI использует временную debug-подпись для эмуляторных тестов. Пользовательский APK после тестов переподписывается постоянным приватным ключом; его резервная копия хранится отдельно и не входит в исходники/отчёты. Для будущих обновлений использовать тот же ключ. Версию 2.1.1 с временной подписью нужно удалить один раз.
