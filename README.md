# GeoHide Switch 2.1.0
Обновление существующей версии 2.0.0. До включения VPN можно выбрать DNS-провайдера и транспорт.

Профили: GeoHide, DNS-AI, Cloudflare, AdGuard DNS, Quad9. Адреса сверены с официальными источниками 13.10.2026.
DNS-AI не предоставляет открытый UDP/53: доступны только HTTPS и TLS. Для новых профилей HTTPS выбран по умолчанию. GeoHide сохраняет прежний UDP-режим по умолчанию. Автоматическая подмена провайдера отсутствует.

Сохранены кнопка питания, явная команда STOP, аварийное отключение и проверка TUN. DNS-only VPN занимает VPN-слот Android. Системный Private DNS не меняется.

Java 17, SDK 35, Gradle 8.11.1. Сборка: `gradle :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug`.
CI проверяет Android 15/16, HTTPS и TLS с локальным сервером, сертификаты, отмену запроса, переключение профиля и сохранение выбора. Неподдерживаемые или недоступные серверы не выдаются за работающие.

Производительность и доступность внешних DNS зависят от сети пользователя; проверка из CI не подтверждает работу конкретного оператора.
Если подпись не совпадает с предыдущим debug-APK, потребуется удаление прежней версии перед установкой.

Описание профилей и источники: DNS_PROVIDERS_RU.md. Фикстура dns-test.p12 используется только тестовым APK, её сертификат не включается в доверенные сертификаты обычного приложения.
